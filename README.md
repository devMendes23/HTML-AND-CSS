# Estudos de HTML e CSS

Exercícios práticos dos fundamentos de front-end: estrutura semântica, tipografia, listas e estilização.

## O que tem aqui

| Arquivo | Conteúdo |
| :-- | :-- |
| `index.html` / `index (1).html` | Fundamentos de HTML: títulos, parágrafos e seções |
| `estrutura.html` | Estrutura básica de um documento HTML |
| `desafio.html` | Desafio prático com imagem e texto |
| `styles.css`, `titles.css`, `lists.css` | Estilos separados por responsabilidade |

## Como abrir

Baixe o repositório e abra qualquer `.html` no navegador. Não precisa instalar nada.

## Tecnologias

HTML5 · CSS3
